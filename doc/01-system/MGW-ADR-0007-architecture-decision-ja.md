# MGW-ADR-0007 アプリ名と見た目

## 状況

『ギャラクシーウォーズ』は元の会社の作品名で、このアプリは公開リポジトリから公開する（MGW-PB-0001 §8）。

## 選択肢

1. 作品名を使わない独自の名前にし、絵と音を自作する。
2. 「ギャラクシーウォーズミニ」とし、絵と音を自作する。
3. 独自の名前にし、タイトル画面に「Tribute to Galaxy Wars (1979)」とだけ出す。

## 決定

選択肢 2（オーナーの決定、2026-10-26）。2026-10-28 に、名前を「銀河戦争ミニ」に変えた（オーナーの決定。doc/requests/2026-10-28-spec-1.6-video-review.md）。

- アプリ名は「銀河戦争ミニ」。マニフェストの `name`・`short_name` と、タイトル画面の名前をこの名前とする。
- 絵（UFO・ミサイル・隕石・文字）は、仕様書の大きさと形を元に自分で描く。原作の画面の画像・ROM のデータは使わない。
- 音は Web Audio で合成する（仕様書 §22）。原作の音の録音は使わない。
- README に、1979 年の原作の再現を目的とした非公式の作品であることと、原作の権利者を書く。タイトル画面には書かない（仕様書 v1.6）。

## 理由

- オーナーの選んだ名前で、仕様書の目的（原作の再現）と合う。
- 絵と音を自作すれば、原作の素材をそのまま配ることを避けられる。

## 影響

- 作品名を使うことで問題になる恐れは残る（オーナーが了承済み）。指摘を受けたら、変更の依頼として名前を変える。
