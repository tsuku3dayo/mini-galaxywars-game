# MGW-TD-0003 render の設計

## 1. 関数

| 関数 | 中身 |
| :--- | :--- |
| `createRenderer(canvas): Renderer` | 2D コンテキストを取り、`imageSmoothingEnabled = false` にする |
| `renderer.resize(scale, dpr)` | Canvas の画素を `480 × scale × dpr` × `640 × scale × dpr` にし、`setTransform(scale × dpr, …)` で論理座標のまま描けるようにする |
| `renderer.draw(state: GameState \| null, view: { mode: 'cellophane' \| 'pixel'; showHud: boolean; tick: number })` | 1 回の描画。`state` が null（タイトル・ランキング）のときは背景と飾りだけ |

render は `GameState` を読むだけで、書き換えない（MGW-ADR-0001）。

## 2. 描く順番

1. 黒で全体を塗る。
2. 隕石（尾つき）→ 光線（2 コマ）→ UFO（2 コマ）→ 発射台（発射前だけ）→ ミサイル → バックファイア → 爆発（ミス）→ UFO を倒したときの爆発・得点（§6）。
   - 発射台を描くのは、`status === 'ready'`（一時停止中は `pausedFrom === 'ready'`）のときだけ。発射したら（playing）描かない。respawn・standby の間も描かない（仕様書 v1.7。前は playing の間も描いていた）。
   - ミサイルは、ready・playing（とその一時停止）のときに描く（今までどおり）。
3. 地面と残機（§6）。
4. HUD（`SCORE`・5 桁、`HIGH`・5 桁）。
5. 擬似カラー（`mode === 'cellophane'` のとき。§5）。
6. 被弾フラッシュ（`flashSteps > 0` のとき。どちらの方式でも）：全体を `#FF0000` で塗る。

## 3. ドット絵（`sprites.ts`）

文字列の配列で 1 ビットの絵を持ち、`fillRect` で 1 ドットずつ描く（起動のときに `OffscreenCanvas` か `canvas` に一度描いておき、`drawImage` で写す）。

| 絵 | 大きさ（論理 px） | 形 |
| :--- | :--- | :--- |
| UFO | 32 × 24 | 上がドーム、真ん中が円盤、下に中央のふくらみ（12 × 8）と 2 本の突起（6 × 8）。部位の四角（MGW-TD-0002 §7.1）と形をそろえる。2 コマ（突起と円盤の端を上下に動かし、羽ばたくように見せる）。コマは `floor(tick ÷ 30) mod 2`（0.25 秒ごと）で、8 機とも同じコマ |
| ミサイル | 12 × 24 | 先のとがった形 |
| 発射台 | 48 × 16 | 台形。中央にミサイルの差し込み口 |
| 隕石 | 24 × 24 | でこぼこの丸。当たりは 20 × 20 |
| 隕石の尾 | 8 × 7 | 3 本の横線（長さ 8、間 2）。進む向きの反対側に、隕石の端に付けて描く（右へ進むときは左、左へ進むときは右） |
| 光線 | 4 × 16 | 波の形（ニョロニョロ線）の 2 コマ。1 コマ目は左上から始まる波、2 コマ目はそれを左右に裏返した波にし、ひと目で形が違うと分かるようにする（前は同じ波を 2 行ずらしただけで、違いが見えなかった）。コマは UFO と同じ `ufoFrame(tick)`（0.25 秒ごと、UFO と同じ時。仕様書 v1.7） |
| バックファイア | 8 × 12 | 噴射中だけ、ミサイルの下に。`tick` で点滅 |
| 爆発 | 32 × 32 | 2 枚を `explosion.steps` で切り替え |
| 残機のアイコン | 16 × 6 | 発射台の縮小 |
| UFO を倒したときの爆発 | 32 × 32 | ミスの爆発と同じ絵 |

- UFO が画面の端をまたぐときは、反対の端にも描く。

## 4. フォント

- 5 × 7 のドット文字を 8 × 8 の枠に入れた自前のフォント。`0-9`・`A-Z`・空白と `! ? : . - / ( )` を持つ。
- HUD は 2 倍（1 文字 16 × 16 論理 px）。`SCORE 00150` を左上（x 12, y 8）、`HIGH 03000` を右上（右端 x 468, y 8）に出す。残機は §6 で左下に出す。
- `READY`・`PAUSE`・`GOOD!!` などの大きい文字は DOM（MGW-TD-0004）で出す。Canvas に描くのは HUD だけ。
- 出撃待ちの「タップで出撃」も、日本語なので DOM で出す（MGW-TD-0004）。ゲーム画面の枠・操作空間の枠も CSS で描く。

## 5. 擬似カラー（`color-palette.ts`）

`globalCompositeOperation = 'multiply'` で色の帯を重ね、白い絵だけに色を乗せる（黒はそのまま黒）。

| 帯（論理 y） | 色 |
| :--- | :--- |
| 0–120 | `#FF50D0`（紫・赤系） |
| 120–580 | 重ねない（白） |
| 580–640 | `#50FF70`（緑系） |

- ピクセルパーフェクトでは重ねない。Canvas の CSS に `image-rendering: pixelated` を付け、拡大でぼやけないようにする（MGW-US-0029）。
- 被弾フラッシュは帯のあとに `source-over` で全体を `#FF0000`。

## 6. 地面・残機・UFO を倒したとき（仕様書 v1.6）

| 物 | 場所 | 描き方 |
| :--- | :--- | :--- |
| 地面 | y 616〜618、x 0〜480 | 白で塗る（セロハンの緑の帯の中なので緑に見える） |
| 残機の数 | 左下（x 12, y 620） | HUD と同じ 2 倍の文字で `lives`（画面に出ている 1 基を含む）。0〜9 を出す |
| 控えの発射台のアイコン | 数の右（x 36 から 20 px おき, y 625） | `lives − 1` 個（0 個以上）。16 × 6 の残機のアイコン |
| UFO を倒したときの爆発 | `killEffect` の (x, y) を中心 | `killEffect.steps > 72`（倒してから 0.4 秒）の間 |
| UFO を倒したときの得点 | `killEffect` の (x, y) を中心 | 爆発のあと、`steps` が 0 になるまで。HUD と同じ 2 倍の文字で `points`（`50`・`100`・`150`・`600`） |

- どれも Canvas に描き、セロハン（§5）とフラッシュも同じように重なる。
- 残機の数とアイコンの数は、`lifeModel(lives) → { count, icons }` の関数で決め、単体テストで確かめる。UFO と光線のコマ・隕石の尾の向き・`killEffect` の出し分け・発射台を描くかどうか（`showsLauncher(state)`）も、Canvas に触れない関数にして単体テストで確かめる。

## 7. 確かめ方

- 描く中身は Canvas なので E2E から読めない。描く元の値（状態・表示方式・フラッシュ）を body の data 属性で確かめ（MGW-TD-0004 §6）、見た目は手動で確かめる。
- `color-palette.ts` の帯の範囲と色、`sprites.ts` のフォントの文字の数・ドット絵の大きさは単体テストで確かめる。
