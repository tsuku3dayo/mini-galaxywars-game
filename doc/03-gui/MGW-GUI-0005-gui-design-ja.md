# MGW-GUI-0005 ランキング画面（`#/ranking`）

## 1. 配置（「ブロック崩しミニ」のランキング画面と同じ形。紺の画面、MGW-GUI-0001 §5.1）

```
┌────────────────────────────────────┐
│ [← BACK]  ハイスコアランキング       │ ← スクロールしても上に残る
│                                    │
│ 順位  名前                   スコア │
│ ────────────────────────────────── │
│ 1st   たあ                    1,520 │ ← 1〜3 位は黄色
│       ✓ CLEAR · 95.7 秒 · 2026/10/25 21:13 │
│ ────────────────────────────────── │
│ 2nd   はる                    1,230 │
│       ✕ GAME OVER · 2026/10/25 20:50│
│ ────────────────────────────────── │
│ ┃5    たあ（あなた）          1,100 │ ← 今登録した記録（黄色の線と背景）
│ ┃     ✓ CLEAR · 2026/10/26 21:16    │
│ ...                                │
│ 10    PLAYER                    380 │
│       2026/10/01 09:50              │ ← 結果のない前からの記録
│ ────────────────────────────────── │
│ ╭────────────────────────────────╮ │
│ │ 記録のバックアップ               │ │
│ │ [⤓ 記録を書き出す][⤒ 記録を読み込む]│ │
│ ╰────────────────────────────────╯ │
└────────────────────────────────────┘
```

## 2. 部品

| 部品 | 文言 | 動き | US |
| :--- | :--- | :--- | :--- |
| 戻る | ← の印と「BACK」 | `#/title` へ。上に残る | MGW-US-0026 |
| 見出し | ハイスコアランキング | 上に残る | MGW-US-0026 |
| 一覧の見出し | 順位・名前・スコア | — | MGW-US-0026 |
| 順位 | 1〜3 位は `1st`・`2nd`・`3rd`（黄色の太字）、4 位からは `4`〜`10` | — | MGW-US-0026 |
| 名前 | 登録した名前（日本語も） | 8 文字まで出す（切らない）。今登録した記録には「（あなた）」を付ける | MGW-US-0026 |
| 結果と日時 | 名前の下に、うすい字で `✓ CLEAR · 95.7 秒 · 2026/10/25 21:13` か `✕ GAME OVER · …`。クリアにはタイム（仕様書 v1.9）。結果やタイムのない前からの記録は、あるものだけ | 日時は端末の時刻で `YYYY/MM/DD HH:MM` | MGW-US-0026 |
| スコア | 等幅の数字、3 けたごとのカンマ（`1,520`）。右にそろえる | — | MGW-US-0026 |
| 今登録した記録 | 行の左に黄色の線、背景を少し明るく | 登録から移ってきたときだけ（ほかから開いたときは目立たせない） | MGW-US-0026 |
| 記録がないとき | まだ記録がありません | 一覧の代わりに出す | MGW-US-0026 |
| 記録のバックアップ | 枠の見出し「記録のバックアップ」 | — | MGW-US-0027 |
| 書き出し | ⤓ の印と「記録を書き出す」 | `mini-galaxywars-ranking-YYYYMMDD.json` を保存する | MGW-US-0027 |
| 読み込み | ⤒ の印と「記録を読み込む」 | ファイルを選ぶ → 「今のランキングを置き換えます。よろしいですか？」→「置き換える」「やめる」 | MGW-US-0027 |
| 読み込めないとき | このファイルは読み込めません | 今の記録は変えない | MGW-US-0027 |
| 更新の案内 | MGW-GUI-0007 | 新しい版があるときだけ | MGW-US-0003 |

## 3. メモ

- 一覧はゲーム画面の枠の中でスクロールする（iPhone SE でも 10 件と記録のバックアップまで見られる）。ページ全体はスクロールさせない（MGW-GUI-0001 §4）。
- 仕様書 v1.7 で、「RANKING」「TITLE」「書き出し」「読み込み」の黒い画面から、この形に変えた。
