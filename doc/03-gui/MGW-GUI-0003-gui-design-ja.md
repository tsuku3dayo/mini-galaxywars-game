# MGW-GUI-0003 プレイ画面（`#/play`）

## 1. 配置

```
上のバー                                         [Pause]
┌────────────────────────────────────────────────┐ y=0
│ SCORE 00150                      HIGH 03000    │ HUD 帯
├────────────────────────────────────────────────┤ y=48
│   🛸   🛸  100  🛸        →（上段。倒した所に得点） │
│ 🛸   🛸   🛸   🛸          ←（下段）             │ y=120
│      ⌇（光線）                                  │
│      ≡🪨       ≡🪨       🪨≡                   │
│   🪨        🪨                                  │
│                 ▲（ミサイル） ✱（バックファイア）   │
│                [▲]（発射台）                     │ y=580–616
│ ══════════════════════════════════（地面） │ y=616–618
│ 3 ▭ ▭（残機の数と控えの発射台）                  │ y=620–636
└────────────────────────────────────────────────┘ y=640
┌────────────────────────────────────────────────┐
│  ◀ ─ ─ なぞって移動 ・ タップで発射 ─ ─ ▶        │ 操作空間（タッチだけ）
└────────────────────────────────────────────────┘
```

## 2. 部品

| 部品 | 文言・形 | 動き | US |
| :--- | :--- | :--- | :--- |
| スコア | `SCORE` と 5 桁のゼロ詰め | 得点で増える | MGW-US-0015 |
| ハイスコア | `HIGH` と 5 桁 | ランキングの 1 位と今のスコアの大きい方 | MGW-US-0015 |
| 残機 | 左下に数（画面に出ている 1 基を含む）と、控えの発射台のアイコン（16 × 6、数 − 1 個） | ミス・増機で増減 | MGW-US-0015、MGW-US-0019 |
| 地面 | 発射台の下の横線 | — | MGW-US-0015 |
| 一時停止のボタン | Pause | 上のバーの右。押すと一時停止 | MGW-US-0018 |
| 発射台・ミサイル | 48 × 16 / 12 × 24 | 指・マウス・キーの横の動きを追う | MGW-US-0006、MGW-US-0007 |
| バックファイア | ミサイルの下の炎（点滅） | 噴射中だけ | MGW-US-0007 |
| UFO・光線・隕石・爆発 | 自作のドット絵（大きさは 04）。UFO は 2 コマで羽ばたく。隕石には進む向きの後ろに尾 | — | MGW-US-0008〜0013 |
| UFO を倒したとき | 倒した位置に爆発（0.4 秒）、そのあと入った得点（`50`・`100`・`150`・`600`） | 倒してから 1 秒で消える | MGW-US-0013 |
| 操作空間 | `なぞって移動 ・ タップで発射` と、左右の矢印 | タッチ端末だけ | MGW-US-0021 |

## 3. タッチの決まり（操作空間とプレイ空間の両方）

| 指の動き | 発射前（Ready） | 発射後（Playing） |
| :--- | :--- | :--- |
| 触れる | 発射台が指の x へ動く。指を離すと発射する | ミサイルが指の x へ動き、触れている間は加速噴射 |
| なぞる | 発射台が指の x を追う | ミサイルが指の x を追う |
| 離す | 発射（「タップで発射」） | 噴射が止まる |

- 発射を「離したとき」にするのは、なぞって位置を決めてから撃てるようにするため（試作で確かめる）。
- 上のバーの Pause は、この決まりの外（押しても発射・移動しない）。

## 4. 状態ごとの表示（ゲーム画面の中央）

| 状態 | 表示 | 次へ | US |
| :--- | :--- | :--- | :--- |
| 発射前（Ready） | なし（最初の 1 回だけ `READY` を 1 秒） | 発射で Playing | MGW-US-0006 |
| ミス | 爆発と赤のフラッシュ（`#FF0000`、100 ms） | 2 秒で Ready | MGW-US-0011、MGW-US-0016、MGW-US-0028 |
| 一時停止 | `PAUSE` と「RESUME」ボタン。うしろは暗くする | `P`・`Esc`・Pause・RESUME で再開 | MGW-US-0018 |
| クリア | `GOOD!!` と、その下に `STAGE CLEAR` | 3 秒でランキング登録（MGW-GUI-0004）か、「TITLE」ボタン | MGW-US-0017 |
| ゲームオーバー | `GAME OVER` | 3 秒でランキング登録（MGW-GUI-0004）か、「TITLE」ボタン | MGW-US-0016 |

## 5. デバッグ表示（`?debug=1` のときだけ）

左下に、fps・1 秒あたりのステップ数・状態を小さく出す（MGW-US-0030、MGW-US-0031）。詳しくは 04 で決める。
