# MGW-GUI-0003 プレイ画面（`#/play`）

## 1. 配置

```
┌────────────────────────────────────────────────┐ y=0（細い枠）
│ SCORE 00150                      HIGH 03000    │ HUD 帯
├────────────────────────────────────────────────┤ y=48
│   🛸   🛸  100  🛸        →（上段。倒した所に得点） │
│ 🛸   🛸   🛸   🛸          ←（下段）             │ y=120
│      ⌇（光線）                                  │
│      ≡🪨       ≡🪨       🪨≡                   │
│   🪨        🪨                                  │
│                 ▲（ミサイル） ✱（バックファイア）   │
│                [▲]（発射台。発射前だけ）          │ y=580–616
│ ══════════════════════════════════（地面） │ y=616–618
│ 3 ▭ ▭（残機の数と控えの発射台）                  │ y=620–636
└────────────────────────────────────────────────┘ y=640
╭────────────────────────────────────────────────╮
│        ここをなぞって移動・タップで発射          │ 操作空間（タッチだけ。角の丸い枠）
╰────────────────────────────────────────────────╯
[ ‖ 一時停止 ]                    [ 🔊 効果音：オン ]   ボタンの段
```

## 3. タッチの決まり（操作空間とプレイ空間の両方）

| 指の動き | 発射前（Ready） | 発射後（Playing） | 出撃待ち |
| :--- | :--- | :--- | :--- |
| 触れる | 発射台が指の x へ動く | ミサイルが指の x へ動き、触れている間は加速噴射 | 何もしない |
| なぞる | 発射台が指の x を追う | ミサイルが指の x を追う | 何もしない |
| 離す（触れてから 10 px 未満しか動いていない＝タップ） | 発射 | 噴射が止まる | 出撃（発射台が x = 240 に出る。発射はしない） |
| 離す（10 px 以上動いた） | 何もしない（移動だけ） | 噴射が止まる | 何もしない |

- 発射を「タップ」だけにするのは、なぞって位置を決めて離したときに、思わず発射しないようにするため（仕様書 v1.7。前は離すと必ず発射していた）。
- マウスも同じ（ボタンを押してから離すまでに 10 px 未満ならクリック）。`Space` は押したときに発射・出撃する。
- ボタンの段の一時停止・効果音は、この決まりの外（押しても発射・移動・出撃しない）。

## 4. 状態ごとの表示（ゲーム画面の中央）

| 状態 | 表示 | 次へ | US |
| :--- | :--- | :--- | :--- |
| 発射前（Ready） | なし（最初の 1 回だけ `READY` を 1 秒） | 発射で Playing | MGW-US-0006 |
| ミス | 爆発と赤のフラッシュ（`#FF0000`、100 ms） | 2 秒で出撃待ち | MGW-US-0011、MGW-US-0016、MGW-US-0028 |
| 最上部を抜けた・UFO を倒した | なし（倒したときは爆発と得点） | 1 秒で出撃待ち | MGW-US-0016 |
| 出撃待ち | タッチ：`タップで出撃`、PC：`クリック/SPACEで出撃`。「ブロック崩しミニ」の「タップ / Space で発射」と同じく、ゲーム画面の中ほどに、うすい色（`#8C96AD`）の端末の文字で重ねて出す（ビットマップフォントには日本語がないので、Canvas ではなく画面の部品で出す） | タップ・クリック・`Space` で Ready | MGW-US-0016 |
| 一時停止 | `PAUSE` と「RESUME」ボタン。うしろは暗くする | `P`・`Esc`・一時停止・RESUME で再開 | MGW-US-0018 |
| クリア | `GOOD!!` と、その下に `STAGE CLEAR`。その下に 4 行：`UFO 01150`・`TIME 95.7`・`BONUS 00425`・`TOTAL 01575`（仕様書 v1.9） | 3 秒でランキング登録（MGW-GUI-0004）か、「TITLE」ボタン | MGW-US-0017 |
| ゲームオーバー | `GAME OVER` | 3 秒でランキング登録（MGW-GUI-0004）か、「TITLE」ボタン | MGW-US-0016 |
