# MGW-GUI-0004 ランキング登録（名前の入力）

クリアかゲームオーバーでゲームが終わり、スコアが上位 10 件に入るとき、プレイ画面の上に重ねて出す。

## 1. 配置

```
┌────────────────────────────────┐
│        NEW RECORD!             │
│         3RD  01250             │
│                                │
│   名前を入れてください           │
│   ┌──────────────────────┐     │
│   │ PLAYER               │     │  ← 入力欄（画面の上半分に置く）
│   └──────────────────────┘     │
│   8 文字まで（日本語も使えます）   │
│                                │
│      [ 登録 ]   [ スキップ ]     │
└────────────────────────────────┘
```

## 2. 部品

| 部品 | 文言 | 動き | US |
| :--- | :--- | :--- | :--- |
| 見出し | NEW RECORD! | — | MGW-US-0025 |
| 順位とスコア | `1ST`〜`10TH` と 5 桁 | 入る順位を出す | MGW-US-0025 |
| 入力欄 | 初めの値 `PLAYER` | ひらがな・カタカナ・漢字・英数字・記号・空白、1〜8 文字。大文字には直さない。改行などの制御文字は入れない。日本語の変換の途中（確定する前）は削らず、確定したときに 8 文字で切る | MGW-US-0025 |
| 案内 | 8 文字まで（日本語も使えます） | — | MGW-US-0025 |
| 登録 | 登録 | 前後の空白を取り（空なら `PLAYER`）、結果（クリア・ゲームオーバー）と一緒に保存して `#/ranking` へ。今入れた記録を目立たせる（MGW-GUI-0005）。キーボードの「完了」でも同じ（変換を確定する Enter では送らない） | MGW-US-0025 |
| スキップ | スキップ | 保存せずに `#/title` へ | MGW-US-0025 |

## 3. メモ

- 入力欄は画面の上半分に置き、ソフトウェアキーボードに隠れないようにする（試作で確かめる）。
- 名前は、ランキング画面（端末の文字で出す）でだけ出す。ゲーム画面のビットマップフォントでは出さないので、日本語を使える（仕様書 v1.7。前は英数字だけだった）。
- iPhone で、入力欄の `autocapitalize` は `off` にする（日本語を打ちやすくするため）。
