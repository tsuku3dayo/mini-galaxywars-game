# MGW-GUI-0007 更新の案内と起動の復旧

## 1. 更新の案内（タイトル・ランキングの下に重ねる）

```
┌────────────────────────────────┐
│ 新しい版があります    [ 更新 ]   │
└────────────────────────────────┘
```

| 部品 | 文言 | 動き | US |
| :--- | :--- | :--- | :--- |
| 案内 | 新しい版があります | 新しい版が待っているときだけ、ゲーム画面の枠の下端に出す | MGW-US-0003 |
| 更新 | 更新 | 新しい版に切り替えて読み込み直す | MGW-US-0003 |

- プレイ画面（`#/play`）では出さない。

## 2. 起動の復旧（boot.js が出す。アプリの画面の代わり）

```
┌────────────────────────────────┐
│   起動できませんでした            │
│                                │
│   [ 再読み込み ]                │
│   [ キャッシュを消して再読み込み ] │
│                                │
│   ランキングは消えません          │
└────────────────────────────────┘
```

| 部品 | 文言 | 動き | US |
| :--- | :--- | :--- | :--- |
| 見出し | 起動できませんでした | 8 秒たっても起動しないときに出す | MGW-US-0004 |
| 再読み込み | 再読み込み | そのまま読み込み直す | MGW-US-0004 |
| キャッシュを消す | キャッシュを消して再読み込み | Service Worker の登録とキャッシュを消してから読み込み直す | MGW-US-0004 |
| 補足 | ランキングは消えません | — | MGW-US-0004 |

- boot.js はアプリより先に動くので、この画面は HTML と最小の CSS だけで作る（ビットマップフォントは使わない）。
