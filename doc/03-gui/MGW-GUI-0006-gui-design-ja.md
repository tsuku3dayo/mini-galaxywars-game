# MGW-GUI-0006 設定（表示方式）と擬似カラー

## 1. 設定（タイトル画面の上に重ねる）

```
┌────────────────────────────────┐
│           SETTINGS             │
│                                │
│  表示方式                       │
│   (●) 擬似カラーセロハン         │
│   ( ) ピクセルパーフェクト        │
│                                │
│          [ 閉じる ]             │
└────────────────────────────────┘
```

| 部品 | 文言 | 動き | US |
| :--- | :--- | :--- | :--- |
| 見出し | SETTINGS | — | MGW-US-0029 |
| 表示方式 | 擬似カラーセロハン／ピクセルパーフェクト | 選ぶとすぐ保存（`mini-galaxywars-settings`）。初めは擬似カラーセロハン | MGW-US-0029 |
| 閉じる | 閉じる | タイトル画面に戻る | MGW-US-0029 |

## 2. 擬似カラーセロハンの色（仕様書 §19）

| 範囲（論理 y） | 色 |
| :--- | :--- |
| 0–120（HUD・UFO 域） | 紫・赤系（例：`#FF40C0` を乗算） |
| 120–580（隕石域） | 白（色を重ねない） |
| 580–640（発射台域） | 緑系（例：`#40FF60` を乗算） |

- 白い図形にだけ色が乗るように、Canvas の合成（`multiply`）で重ねる。正確な色は 04 で決める。
- ピクセルパーフェクトでは色を重ねず、白黒で描く。拡大は `imageSmoothingEnabled = false`。
- 被弾フラッシュは、どちらの方式でも画面全体を `#FF0000` で 100 ms（MGW-US-0028）。
