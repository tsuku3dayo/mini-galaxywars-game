# MGW-GUI-0002 タイトル画面（`#/title`）

## 1. 配置（ゲーム画面の枠の中）

```
┌────────────────────────────────┐
│ HIGH 03000                     │
│                                │
│          銀河戦争ミニ            │
│                                │
│                                │
│        🛸  🛸  🛸               │
│                                │
│         [ START ]              │
│         [ RANKING ]            │
│         [ SETTINGS ]           │
│  [CREDITS] [ランキング消去]      │  ← 小さめのボタン
│       [ 🔊 効果音：オン ]        │
│                                │
│   ←→/マウスで移動 SPACEで発射     │
│   （タッチ：なぞって移動・タップ） │
└────────────────────────────────┘
```

- START・RANKING・SETTINGS は今の大きさのまま。CREDITS・ランキング消去・効果音は、文字を小さめ（16 pt）にし、CREDITS とランキング消去を 1 段に、効果音をその下に並べる（iPhone SE の高さで枠に収めるため。押せる大きさは 44 pt 以上。収まることは E2E で確かめる）。

## 2. 部品

| 部品 | 文言 | 動き | US |
| :--- | :--- | :--- | :--- |
| アプリ名 | 銀河戦争ミニ | — | MGW-US-0014 |
| ハイスコア | `HIGH` と 5 桁 | ランキングの 1 位。記録がなければ `00000` | MGW-US-0015 |
| 開始 | START | `#/play` へ。`Space` でも同じ。このときに音を有効にする | MGW-US-0014、MGW-US-0024 |
| ランキング | RANKING | `#/ranking` へ | MGW-US-0026 |
| 設定 | SETTINGS | 設定（MGW-GUI-0006）を重ねて出す | MGW-US-0029 |
| クレジット | CREDITS | `#/credits`（MGW-GUI-0008）へ | MGW-US-0033 |
| ランキング消去 | ランキング消去 | 確認を重ねて出す：「ランキングをすべて消します。元に戻せません。よろしいですか？」と「消す」「やめる」。消したら HIGH を `00000` にする。記録がないときは確認の代わりに「記録がありません」と「閉じる」 | MGW-US-0032 |
| 効果音 | スピーカーの印と「効果音：オン」/「効果音：オフ」 | 押すたびに切り替え、保存する。プレイ画面のボタンと同じ設定 | MGW-US-0034 |
| 操作の案内 | PC：`←→/マウスで移動 SPACEで発射`、タッチ：`なぞって移動 タップで発射` | 端末に合わせてどちらかを出す | MGW-US-0014 |
| 更新の案内 | MGW-GUI-0007 | 新しい版があるときだけ | MGW-US-0003 |

## 3. メモ

- iPhone では、最初の「START」のタッチで Web Audio を有効にする（MGW-US-0024）。効果音がオフでも有効にしておく（オンに戻したらすぐ鳴るように）。
- ランキング消去・効果音のボタンを押しても、`Space` でゲームが始まらないよう、押したらフォーカスを外す。
