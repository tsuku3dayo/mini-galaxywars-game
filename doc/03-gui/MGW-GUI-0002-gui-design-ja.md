# MGW-GUI-0002 タイトル画面（`#/title`）

## 1. 配置（ゲーム画面の枠の中）

```
┌────────────────────────────────┐
│ HIGH 03000                     │
│                                │
│        ギャラクシーウォーズ        │
│             ミニ                │
│                                │
│        🛸  🛸  🛸               │
│                                │
│         [ START ]              │
│         [ RANKING ]            │
│         [ SETTINGS ]           │
│                                │
│   ←→/マウスで移動 SPACEで発射     │
│   （タッチ：なぞって移動・タップ） │
│                                │
│ 原作 1979 ユニバーサル／タイトー  │
│ 非公式の再現作品                 │
└────────────────────────────────┘
```

## 2. 部品

| 部品 | 文言 | 動き | US |
| :--- | :--- | :--- | :--- |
| アプリ名 | ギャラクシーウォーズミニ | — | MGW-US-0014 |
| ハイスコア | `HIGH` と 5 桁 | ランキングの 1 位。記録がなければ `00000` | MGW-US-0015 |
| 開始 | START | `#/play` へ。`Space` でも同じ。このときに音を有効にする | MGW-US-0014、MGW-US-0024 |
| ランキング | RANKING | `#/ranking` へ | MGW-US-0026 |
| 設定 | SETTINGS | 設定（MGW-GUI-0006）を重ねて出す | MGW-US-0029 |
| 操作の案内 | PC：`←→/マウスで移動 SPACEで発射`、タッチ：`なぞって移動 タップで発射` | 端末に合わせてどちらかを出す | MGW-US-0014 |
| 原作の表記 | 原作 1979 ユニバーサル／タイトー、非公式の再現作品 | — | MGW-ADR-0007 |
| 更新の案内 | MGW-GUI-0007 | 新しい版があるときだけ | MGW-US-0003 |

## 3. メモ

- iPhone では、最初の「START」のタッチで Web Audio を有効にする（MGW-US-0024）。
