# MGW-GUI-0002 タイトル画面（`#/title`）

## 1. 配置（ゲーム画面の枠の中）

```
┌────────────────────────────────┐
│ HIGH 03000              v1.0.0 │  ← 版（小さく、うすい色）
│          銀河戦争ミニ            │
│                                │
│        ┌──────────── 50        │  ← 点数の説明（UFO は紫・赤、線と数字は白）
│       🛸                        │
│       │  ╲                     │
│      150  100                  │
│     4 機目の突起は 600           │
│                                │
│         [ START ]              │
│         [ RANKING ]            │
│         [ SETTINGS ]           │  ← 5 つとも同じ大きさ
│         [ CREDITS ]            │
│      [ 🔊 効果音：オン ]         │
│                                │
│   ←→/マウスで移動 SPACEで発射     │
│   （タッチ：なぞって移動・タップ） │
│        [ランキング消去]          │  ← 小さめのボタン
└────────────────────────────────┘
```

- START・RANKING・SETTINGS・CREDITS・効果音は、同じ大きさ（幅・高さとも START と同じ）で縦に並べる（仕様書 v1.8）。
- ランキング消去は小さめ（文字 16 pt）で、操作の案内の下に置く。押せる大きさは 44 pt 以上。
- 点数の説明（仕様書 §18、§6.1・§6.2）：UFO の絵を 2 倍に拡大して描き、部位から白い線を引いて得点を書く。側面・上部から右へ水平の線で `50`、下部中央から右下へ斜めの線で `100`、下部の突起から真下へ線で `150`（添付の元のゲームの説明と同じ並び）。数字はゲーム画面と同じドットの文字。その下に小さく「4 機目の突起は 600」。絵・線は自作（MGW-ADR-0007）。
- ゲーム画面の枠に収まらない小さい画面（iPhone SE の Safari など）では、タイトル画面の中身を枠の中でスクロールできるようにする。START はスクロールしなくても見える所に置く。ページ全体はスクロールさせない（MGW-GUI-0001 §4）。iPhone 11 ではスクロールせずに収まる。
- 版（仕様書 v1.11）：HIGH と同じ行の右端に `v1.0.0` の形で出す。HIGH より小さい文字（13 pt）で、うすい色。HIGH と同じく中身のスクロールには入れず、いつも見える。行の高さは増やさない（iPhone 11 ではランキング消去の下に 15 px ほどしか余りがないため、中身の行には足さない）。

## 3. メモ

- iPhone では、最初の「START」のタッチで Web Audio を有効にする（MGW-US-0024）。効果音がオフでも有効にしておく（オンに戻したらすぐ鳴るように）。
- ランキング消去・効果音のボタンを押しても、`Space` でゲームが始まらないよう、押したらフォーカスを外す。
- 中身をスクロールできるようにしても、`Space` はゲームを始める（中身をスクロールさせない）。
