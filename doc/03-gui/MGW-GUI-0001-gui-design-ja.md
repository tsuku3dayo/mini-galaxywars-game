# MGW-GUI-0001 共通の画面の枠

## 1. 基準の端末

- 基準：iPhone 11（画面 414 × 896 pt、縦）。試作はこの実機で触って確かめる。
- 小さい方の確認：iPhone SE（第 2・3 世代、375 × 667 pt）。E2E で、はみ出さないことを確かめる。
- PC：ブラウザの窓の大きさに合わせる。

## 2. 画面の組み立て

すべての画面は、次の 3 段で組み立てる。

```
┌───────────── 安全領域の上（ノッチ・ステータスバー） ─────────────┐
│ 上のバー（高さ 44 pt）              [Pause]（プレイ中だけ）      │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│   ゲーム画面（Canvas、論理 480 × 640）                            │
│     HUD 帯 0–48 / UFO 48–120 / 隕石 120–580 / 発射台 580–612       │
│                                                                  │
├──────────────────────────────────────────────────────────────────┤
│   操作空間（論理 480 × 96、タッチ端末だけ）                        │
└───────────── 安全領域の下（ホームバー） ─────────────────────────┘
```

- タイトル・ランキングなど、プレイ以外の画面も、同じ枠（480 × 640 の場所）の中に出す。
- 操作空間は、タッチ端末（`pointer: coarse`）のときだけ出す。PC では出さない（MGW-US-0021）。

## 3. 大きさの合わせ方

- 使える広さ：画面の大きさから、安全領域（`env(safe-area-inset-*)`）と上のバー（44 pt）を引いたもの。
- 倍率：`min(使える幅 ÷ 480, 使える高さ ÷ (640 + 操作空間の 96))`。縦横比を保って拡大・縮小する（MGW-US-0005）。
- 余ったところは黒で埋め、ゲーム画面を左右の中央に置く。上下は上のバーの下に詰める。
- Canvas の実際の画素は、倍率 × `devicePixelRatio` にし、ぼやけないようにする。
- 計算の例（実機の値は試作で確かめる）：

| 端末 | 使える広さ（目安） | 倍率 | ゲーム画面＋操作空間 |
| :--- | :--- | :--- | :--- |
| iPhone 11・Safari | 414 × 約 670 pt | 約 0.85（高さで決まる） | 約 408 × 626 pt |
| iPhone 11・ホーム画面のアプリ | 414 × 約 770 pt | 0.8625（幅で決まる） | 414 × 635 pt |
| iPhone SE・Safari | 375 × 約 550 pt | 約 0.69（高さで決まる） | 約 331 × 506 pt |

## 4. 安全領域とスクロール

- `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">` とし、上のバーと操作空間に安全領域ぶんの余白を付ける（MGW-US-0022）。
- ページはスクロールさせない（`overflow: hidden`、`overscroll-behavior: none`、`body` を `position: fixed`）。
- それでもスクロールしたら（キーボードを閉じたあとなど）、すぐ 0 に戻す。iOS のホーム画面のアプリでは、ページが少しスクロールしたままだと、ボタンの押せる位置が見た目より下にずれる（試作で見つかった。§8）。
- ゲーム画面と操作空間では、拡大・長押しのメニュー・文字の選択が起きないようにする（`touch-action: none`、`-webkit-touch-callout: none`、`user-select: none`）。
- ソフトウェアキーボードを使うのは、名前の入力（MGW-GUI-0004）だけ。キーボードが出ても枠の大きさを計算し直さず、入力欄がキーボードに隠れないようにする。

## 5. 色と文字

| もの | 決め |
| :--- | :--- |
| 背景 | 黒 `#000000` |
| 文字・図形 | 白 `#FFFFFF`（擬似カラーの色は MGW-GUI-0006） |
| 選べる部品 | 白い枠の四角。押している間は白地に黒の文字 |
| ゲーム画面の文字 | 自前のビットマップフォント（8 × 8 ドットを拡大）。英数字と記号だけ |
| プレイ以外の画面の文字 | 端末の等幅フォント（`ui-monospace, Menlo, monospace`）の太字。Web フォントは使わない |
| 文字の大きさ | 本文 16 pt 以上、ボタン 18 pt 以上 |
| ボタンの大きさ | 高さ・幅とも 44 pt 以上。となりのボタンとは 8 pt 以上あける |

## 6. アプリの名前

| 場所 | 文言 |
| :--- | :--- |
| マニフェストの `name`、タイトル画面、`<title>` | ギャラクシーウォーズミニ |
| マニフェストの `short_name`（ホーム画面） | GWミニ |

## 7. 画面の一覧

| ID | 画面 | ハッシュ |
| :--- | :--- | :--- |
| MGW-GUI-0002 | タイトル | `#/title` |
| MGW-GUI-0003 | プレイ（HUD・操作空間・一時停止・各表示） | `#/play` |
| MGW-GUI-0004 | ランキング登録（名前の入力） | `#/play` の上に重ねる |
| MGW-GUI-0005 | ランキング（書き出し・読み込み） | `#/ranking` |
| MGW-GUI-0006 | 設定（表示方式）と擬似カラー | `#/title` の上に重ねる |
| MGW-GUI-0007 | 更新の案内・起動の復旧 | タイトル・ランキングの上／単独 |

画面のハッシュは、仕様書 §18 の 3 つだけにする。設定とランキング登録は、ハッシュを増やさず重ねて出す。
