## 2. 手動の確認

この TASK に手動の確認 ID はない。iPhone でソフトウェアキーボードを出したときの見え方は、WS-0006 の終わりに公開 URL で見てもらう。

## 3. 設計と違う作りにしたこと

なし。MGW-TD-0004 のとおりに作り、次を足した。

- 名前の入力欄で打っているキーは、ゲームの操作（`Space`・`←` `→` `A` `D`・`P` `Esc`）にしない（打った文字が消えないように）。
- 入力欄に触れたら全体を選び、打てば `PLAYER` を置き換えられるようにした。
- タイトルの HIGH は、タイトルに入るたびにランキングの 1 位を読み直す。プレイは `newGame(ランキングの 1 位)` で始める。
- 保存に失敗しても（容量など）、ランキング画面へは進む。

## 4. 確認できなかったこと

- iPhone の実機でのソフトウェアキーボードの出方（入力欄が隠れないか、閉じたあとに画面がずれないか）は、E2E では確かめられない。WS-0006 の終わりに見てもらう。
- Android の端末では確かめていない（実機がない。MGW-TST-0001 §6.1）。
