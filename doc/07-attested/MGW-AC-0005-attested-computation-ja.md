## 3. 設計と違う作りにしたこと

- `config.ts` に `REGIONS`（縦の領域）と `LAUNCHER_START_X` を足した。`planSteps` は、12 ステップを超えた分を捨てるときに積み上げを 0 にし、60 Hz の足し算の誤差で 1 ステップ足りなくならないよう 1e-6 ms の余裕を持たせた。MGW-TD-0002 を v1.1 にし、TD-0002 を sources に持つ文書の版の表記を直した。
- 隕石の道のりの位置から x・y を決める `meteorAt` は、初めの状態に要るので `physics.ts` に先に作った（動きは MGW-TASK-0006）。
- `step` は、ステップの数とタイマー（§6 の 1）と、一時停止・クリア・ゲームオーバーで進まないことまでを作った。§6 の 2〜10 は MGW-TASK-0006 以降で足す。そのため、今の決定性のテストは状態の変化が少ない。動きを足すたびに、同じテストで確かめ直す。
- ESLint で、`_` で始まる引数を「使わない」の印として許した（`step` の入力は MGW-TASK-0006 から使う）。
