# MGW-AC-0020 擬似カラーと被弾フラッシュの確認

* **TASK**：MGW-TASK-0020（ブランチ `feat/TASK-0020-cellophane-flash`）
* **確かめた環境**：Windows 11、Node.js v24.0.0、Vitest 5.0.5、Playwright 1.64.1

## 1. 自動テストの結果

| 確認 ID | 確かめること | 結果 | 根拠 |
| :--- | :--- | :--- | :--- |
| MGW-TC-0028-02 | ミスすると、画面全体が `#FF0000`（赤）で 100 ms フラッシュする | OK | `✓ tests/unit/color-palette.test.ts > 擬似カラーと被弾フラッシュ > MGW-TC-0028-02 …`。隕石に当ててミスにすると、重ねるものの最後に全体（480 × 640）の `#FF0000`（`source-over`）が入る。セロハンでもピクセルパーフェクトでも同じ。出ている間を数えると 12 ステップ（120 ステップ/秒で 100 ms）で、そのあと消える |

そのほか（同じファイル）：セロハンの帯は、0–120 が `#FF50D0`、580–640 が `#50FF70`（どちらも `multiply`）で、中央（120–580）には重ねない。ピクセルパーフェクトでは帯を重ねない。

単体テストの合計：`Tests 79 passed (79)`。E2E の合計：`115 passed`、`17 skipped`。`npm run verify` も通った。

画面：iPhone 11 と PC（1280 × 800）の幅で、プレイ画面（上の UFO と HUD が紫・赤、隕石と光線が白、発射台とミサイルが緑）と、フラッシュの最中（全体が赤）のスクリーンショットを見た。

なし。MGW-TD-0003 §2・§5 のとおり。重ねる四角を決める処理（`overlaysFor`）を Canvas に触れない関数にして、単体テストで確かめられるようにした。表示方式はまだ切り替えられない（いつもセロハン）。切り替えは MGW-TASK-0021。
