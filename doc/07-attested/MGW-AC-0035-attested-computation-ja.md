## 3. 設計と違う作りにしたこと

- 光線の波：MGW-TD-0003 v1.6 では `#...`〜`#...` の 8 行のくり返しと書いたが、画像を点で読み取った並びと比べると、点の位置は 0・1・2・3・3・2・1 の 7 行でくり返していた（下の折り返しは 1 行）。画像どおりに作り、MGW-TD-0003 を v1.7 にした。
- 名前の入力欄の幅：MGW-TD-0004 v1.5 では「`8em` と余白」としたが（v1.6 で直した）、全角の文字の幅はフォントによって 1em より少し広く（PC で約 1.14em）、8 文字が収まらなかった。9.5 文字ぶん（`calc(9.5em + 20px)`）にした。CI の Linux のフォントの違いも見込んだ。
- 出撃のタップの位置は、指を離した位置（`pointerup` の x）にした（MGW-TD-0004 のとおり）。
