## やること

- ranking.ts：「ブロック崩しミニ」と同じ形（紺の画面、BACK とタイトル、順位・名前・スコア、結果と日時、記録のバックアップ）、登録のあとの自分の記録の目立たせ方（MGW-GUI-0005、MGW-TD-0004 §1）
