# MGW-TASK-0028 プレイ画面：タップの判定・発射後の発射台・出撃の案内・光線の 2 コマ・枠とボタンの段

* **workstream**：MGW-WS-0010
* **ブランチ**：`feat/TASK-0028-play-screen`
* **依存**：MGW-TASK-0027
* **実施記録**：attested-computation の同じ番号（0028）。作るのはこの TASK の PR

## やること

- input.ts：タップの判定（`isTap`、10 CSS px 未満）。なぞって離したときは発射・出撃しない（MGW-TD-0004 §4）
- render：発射台は発射前だけ描く（`showsLauncher`）、光線の 2 コマ（裏返した波、`ufoFrame` で切り替え）（MGW-TD-0003）
- app：出撃待ちの案内（`#standby-hint`）、上のバーをなくしボタンの段（一時停止・効果音のボタンの置き場所）、ゲーム画面と操作空間の枠、`computeLayout` の計算（MGW-TD-0004 §2・§3、MGW-GUI-0001 §5.1）。効果音のボタンは置き場所と見た目だけ（動きは MGW-TASK-0031）
- 種の決め方（`crypto.getRandomValues`）、`?debug=1&seed=<整数>`、`data-seed`（MGW-TD-0004 §1）
- 「Pause」を「一時停止」にする。離して発射する前提の E2E を、タップで発射する形に直す
