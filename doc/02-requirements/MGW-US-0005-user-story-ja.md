# MGW-US-0005 フィールドが仕様書の比率で表示される

* **epic**：MGW-EP-0002
* **優先順位**：2-1
* **種類**：機能

## ストーリー

* **だれが**：プレイヤー
* **したいこと**：画面の大きさに関係なく、同じ形のフィールドで遊ぶ
* **なぜ**：端末によって見え方や難しさが変わらないようにするため

## 受け入れ条件

| No | 条件 | 確かめ方 |
| :--- | :--- | :--- |
| 1 | 論理座標 480 × 640 で計算し、画面には縦横比 3:4 を保って拡大・縮小して表示する | E2E |
| 2 | 領域が HUD 帯 0–48、UFO 通過領域 48–120、隕石往復領域 120–580、発射台待機領域 580–612 になっている | 単体 |

## メモ

- 拡大の仕方（整数倍にするか・余白の色）は 03 で決める。
