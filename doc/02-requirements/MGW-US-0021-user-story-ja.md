# MGW-US-0021 タッチで操作する（操作空間・プレイ空間）

* **epic**：MGW-EP-0004
* **優先順位**：4-1
* **種類**：機能

## ストーリー

* **だれが**：iPhone のプレイヤー
* **したいこと**：指でなぞって動かし、タップで発射し、押し続けて加速する
* **なぜ**：スマートフォンでも PC と同じように遊べるようにするため

## 受け入れ条件

| No | 条件 | 確かめ方 |
| :--- | :--- | :--- |
| 1 | タッチ端末では、フィールドの下に高さ 96 の操作空間が、角の丸い枠に囲まれて出る。中に「ここをなぞって移動・タップで発射」と出る | E2E |
| 2 | 操作空間かプレイ空間をなぞると、発射台（発射後はミサイル）が指の x を追う | E2E |
| 3 | 操作空間かプレイ空間をタップ（触れてから離すまでに 10 px 未満しか動かないもの）すると発射する。なぞって動かしてから離しても発射しない | 単体・E2E |
| 4 | 指を触れ続けている間は、加速噴射になる | E2E |
| 5 | 操作空間で操作するとき、指でミサイル・UFO・光線が隠れない | 手動（iPhone） |

## メモ

- タップ（発射）と押し続け（噴射）の見分け方、操作空間に出す案内の文言は 03 の試作で決める。
- 仕様書 v1.7 で、なぞって離したときに発射しないようにした（思っていないときに発射してしまうため）。
