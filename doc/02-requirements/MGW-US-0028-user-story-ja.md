# MGW-US-0028 擬似カラーと被弾フラッシュ

* **epic**：MGW-EP-0007
* **優先順位**：7-1
* **種類**：機能

## ストーリー

* **だれが**：プレイヤー
* **したいこと**：原作のセロハンを貼った画面の雰囲気で遊ぶ
* **なぜ**：1979 年のアーケードの見た目を再現するため

## 受け入れ条件

| No | 条件 | 確かめ方 |
| :--- | :--- | :--- |
| 1 | 擬似カラーセロハンの表示では、上部（UFO 域）が紫・赤系、中央（隕石域）が透明・白系、下部（発射台域）が緑系になる | 手動（iPhone・PC） |
| 2 | ミスすると、画面全体が `#FF0000`（赤）で 100 ms フラッシュする | 単体・手動（PC） |

## メモ

- 初めの表示方式は擬似カラーセロハンとする（03 で確定）。
