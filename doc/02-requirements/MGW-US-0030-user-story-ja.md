# MGW-US-0030 同じ入力から同じ展開になる（決定性）

* **epic**：MGW-EP-0002
* **優先順位**：2-10
* **種類**：非機能

## ストーリー

* **だれが**：作り手
* **したいこと**：種と入力の記録から、同じゲームの展開を何度でも再現する
* **なぜ**：仕様書の決定性を守り、不具合を再現して直せるようにするため

## 受け入れ条件

| No | 条件 | 確かめ方 |
| :--- | :--- | :--- |
| 1 | 同じ種と同じ入力の列を 2 回流すと、状態とスコアが毎回まったく同じになる | 単体 |
| 2 | 物理は 1/120 秒の固定ステップで進み、1 回の描画で進めるのは最大 12 ステップ | 単体 |
| 3 | 画面の更新が 60 Hz でも 120 Hz でも、同じ入力の列なら同じ結果になる | 単体 |
| 4 | ゲームのルール（src/core）が DOM・時刻・`Math.random` を使っていない（乱数は、app が渡す種から決まった式で作る） | lint |
| 5 | iPhone の実機で、ゲームの時間と実際の時間がずれない（デバッグ表示で、1 秒あたり 120 ステップ進むことを見る） | 手動（iPhone） |
