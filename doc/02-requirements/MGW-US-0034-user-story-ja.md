# MGW-US-0034 効果音をオン・オフする

* **epic**：MGW-EP-0005
* **優先順位**：5-3
* **種類**：機能

## ストーリー

* **だれが**：プレイヤー
* **したいこと**：効果音を消して遊ぶ、また鳴らす
* **なぜ**：電車の中など、音を出せない所でも遊べるようにするため

## 受け入れ条件

| No | 条件 | 確かめ方 |
| :--- | :--- | :--- |
| 1 | タイトル画面とプレイ画面に、「効果音：オン」か「効果音：オフ」のボタン（スピーカーの印つき）がある。プレイ画面では、操作空間の下の右（左は一時停止） | E2E |
| 2 | 押すたびにオンとオフが入れ替わり、タイトル画面とプレイ画面のボタンの表示がそろう | E2E |
| 3 | オフのときは、どの効果音も鳴らない。噴射音が鳴っているときに押すと、すぐ止まる | 単体・手動（iPhone・PC） |
| 4 | 設定は端末に保存され、開き直しても同じ。初めはオン。前からある設定（効果音の項目がないもの）はオンとして読み、表示方式は変わらない | 単体・E2E |
| 5 | プレイ中に押しても、ゲームは止まらず、発射・移動にもならない | E2E |
| 6 | オフで始めてから iPhone でオンに戻すと、すぐ鳴る | 手動（iPhone） |
