# MGW-US-0020 永久パターンを防ぐ

* **epic**：MGW-EP-0003
* **優先順位**：3-7
* **種類**：機能

## ストーリー

* **だれが**：運営（作り手）
* **したいこと**：同じ動きをくり返すだけで終わらないゲームが続かない
* **なぜ**：原作の永久パターン防止を再現するため

## 受け入れ条件

| No | 条件 | 確かめ方 |
| :--- | :--- | :--- |
| 1 | UFO を 1 機も倒さないまま 90 秒たつと、残機が 1 になる | 単体 |
| 2 | そのまま 150 秒たつと、ゲームオーバーになる | 単体 |
| 3 | タイマーは UFO を倒すと 0 に戻る。ミスしても戻らない | 単体 |
