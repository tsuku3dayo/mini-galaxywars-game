# MGW-US-0007 誘導ミサイルを操る（通常上昇・加速噴射）

* **epic**：MGW-EP-0002
* **優先順位**：2-3
* **種類**：機能

## ストーリー

* **だれが**：プレイヤー
* **したいこと**：発射したミサイルを左右に操り、噴射で加速する
* **なぜ**：原作の「ミサイルそのものを操って体当たりする」感覚を味わうため

## 受け入れ条件

| No | 条件 | 確かめ方 |
| :--- | :--- | :--- |
| 1 | 噴射しないときは、上昇 180 px/秒、横 120 px/秒で動き、バックファイアを描かない | 単体 |
| 2 | 噴射中（`Space` を押し続ける・マウスのボタンを押し続ける）は、上昇 280 px/秒、横 240 px/秒になる | 単体 |
| 3 | 噴射中だけ、ミサイルの後ろにバックファイアを描く | 単体・手動（PC） |
| 4 | 敵や隕石に触れずに最上部（y < 48）を抜けても、ミスにならない | 単体 |

## 仕様書 §12 の受け入れ基準との対応

- ボタン押下による加速噴射時に音とバックファイアが発生し、横移動が高速化すること（音は MGW-US-0023）

## メモ

- マウスで操るとき、ミサイルはポインターの x へ横の速さの上限で近づく（04 で確定）。
