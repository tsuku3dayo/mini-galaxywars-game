# MGW-US-0011 当たり判定とミス

* **epic**：MGW-EP-0002
* **優先順位**：2-7
* **種類**：機能

## ストーリー

* **だれが**：プレイヤー
* **したいこと**：当たった・当たらないが見た目どおりに決まる
* **なぜ**：負けたときに納得できるようにするため

## 受け入れ条件

| No | 条件 | 確かめ方 |
| :--- | :--- | :--- |
| 1 | ミサイルが隕石に触れるとミスになり、爆発を描く | 単体 |
| 2 | 発射前のミサイルの先端に隕石が触れてもミスになる | 単体・E2E |
| 3 | ミサイルが UFO に当たると、UFO が壊れ、得点が入る（得点は MGW-US-0013） | 単体 |
| 4 | ミサイルが光線に当たると、弾く範囲（MGW-US-0012）の外ならミスになる | 単体 |
| 5 | 同じステップで複数に当たったときは、隕石 → UFO → 光線の順に判定する | 単体 |

## 仕様書 §12 の受け入れ基準との対応

- 発射台待機中のミサイル先端が隕石と接触してミスになること

## メモ

- 発射前の発射台に光線が当たったときの扱いは仕様書にない。04 で決め、変更の依頼で仕様書に足す。
