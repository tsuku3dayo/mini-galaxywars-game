# MGW-US-0029 表示方式を切り替える

* **epic**：MGW-EP-0007
* **優先順位**：7-2
* **種類**：機能

## ストーリー

* **だれが**：プレイヤー
* **したいこと**：擬似カラーセロハンとピクセルパーフェクトの表示を選ぶ
* **なぜ**：好みの見た目で遊べるようにするため

## 受け入れ条件

| No | 条件 | 確かめ方 |
| :--- | :--- | :--- |
| 1 | 設定で「擬似カラーセロハン」と「ピクセルパーフェクト」を切り替えられる | E2E |
| 2 | ピクセルパーフェクトでは、セロハンの色を重ねず、拡大してもドットがぼやけない | 手動（PC） |
| 3 | 選んだ方式は `mini-galaxywars-settings` に残り、次に開いても同じ方式になる | E2E |

## メモ

- 設定画面の場所と文言は 03 で決める。
