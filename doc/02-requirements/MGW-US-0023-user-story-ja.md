# MGW-US-0023 効果音が鳴る

* **epic**：MGW-EP-0005
* **優先順位**：5-1
* **種類**：機能

## ストーリー

* **だれが**：プレイヤー
* **したいこと**：原作のような効果音を聞きながら遊ぶ
* **なぜ**：緊張感と手ごたえを音で伝えるため

## 受け入れ条件

| No | 条件 | 確かめ方 |
| :--- | :--- | :--- |
| 1 | 加速噴射の間、ミサイルの噴射音（ノイズの「シュー」という音）が鳴る。噴射しないときは鳴らない | 単体・手動（iPhone・PC） |
| 2 | UFO を壊すと破壊音（ホワイトノイズ＋ 120 Hz → 30 Hz の低音）が鳴る | 単体・手動（iPhone・PC） |
| 3 | 増機すると増機音（三角波 523 → 659 → 784 Hz のアルペジオ）が鳴る | 単体・手動（iPhone・PC） |
| 4 | ミスすると爆発音（重低音のノイズ）が鳴る | 単体・手動（iPhone・PC） |
| 5 | 音のファイルを使わず、Web Audio で合成する | check:dist |

## 仕様書 §12 の受け入れ基準との対応

- ボタン押下による加速噴射時に音とバックファイアが発生し、横移動が高速化すること（音の部分）
- 1,000点到達時に増機音が鳴り、発射台アイコンが増加すること（音の部分）

## メモ

- 単体テストでは、どの音をいつ鳴らすかの計画（sound-plan）を確かめる。音色は手動で聞いて確かめる。
