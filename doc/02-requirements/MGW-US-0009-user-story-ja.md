# MGW-US-0009 UFO が光線を撃ってくる

* **epic**：MGW-EP-0002
* **優先順位**：2-5
* **種類**：機能

## ストーリー

* **だれが**：プレイヤー
* **したいこと**：上から降ってくる光線をよける
* **なぜ**：攻めるだけでなく守る緊張感のため

## 受け入れ条件

| No | 条件 | 確かめ方 |
| :--- | :--- | :--- |
| 1 | 0.75 秒ごとに、ミサイル（発射前は発射台）との横の距離がいちばん近い UFO が、真下へ光線を 1 発撃つ | 単体 |
| 2 | 画面内の光線は、UFO が 5 機以上なら 3 発まで、4 機以下なら 4 発まで。上限のときは撃たない | 単体 |
| 3 | 光線は 90 px/秒で落ちる | 単体 |
| 4 | 光線は隕石に当たると消える（隕石が盾になる） | 単体 |
| 5 | 光線は波の形（ニョロニョロ線）で描く | 手動（PC） |

## メモ

- 距離が同じ UFO が 2 機あるときの選び方は 04 で決める。
