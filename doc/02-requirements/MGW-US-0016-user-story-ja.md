# MGW-US-0016 ミスのあとに再登場し、残機がなくなると終わる

* **epic**：MGW-EP-0003
* **優先順位**：3-3
* **種類**：機能

## ストーリー

* **だれが**：プレイヤー
* **したいこと**：ミスしても残機があれば続けられ、なくなると終わる
* **なぜ**：アーケードの残機制を再現するため

## 受け入れ条件

| No | 条件 | 確かめ方 |
| :--- | :--- | :--- |
| 1 | ゲームは発射台 3 基（画面に出ている 1 基を含む）で始まる | 単体 |
| 2 | ミスすると残機が 1 減り、2 秒後に次の発射台が出て、発射前（Ready）に戻る | 単体 |
| 3 | ミスしても、倒した UFO は戻らず、隕石は動き続ける | 単体 |
| 4 | 最上部を抜けたときは、1 秒後に発射台が出て Ready に戻る。残機は減らない | 単体 |
| 5 | 残機が 0 になると、ゲームオーバーの表示が出る。そのあと、スコアが上位 10 件に入るときはランキング登録（MGW-US-0025）に進み、入らないときは「TITLE」でタイトルに戻る | 単体・E2E |
