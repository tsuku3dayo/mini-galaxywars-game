# MGW-US-0012 光線をミサイルの先端で弾く

* **epic**：MGW-EP-0002
* **優先順位**：2-8
* **種類**：機能

## ストーリー

* **だれが**：上級のプレイヤー
* **したいこと**：ミサイルの先端で光線を弾き返す
* **なぜ**：原作の隠し技を再現するため

## 受け入れ条件

| No | 条件 | 確かめ方 |
| :--- | :--- | :--- |
| 1 | ミサイルの先端の中央・横幅 4 px の範囲で、正面の上から光線を受けると、ミスにならずに弾く | 単体 |
| 2 | 弾いた光線は上へ飛び、画面の上で消える。UFO には当たらない | 単体 |
| 3 | 4 px の範囲の外で光線を受けると、ミスになる | 単体 |

## 仕様書 §12 の受け入れ基準との対応

- ミサイル先端での光線受弾時に弾き（Reflect）が正しく発動すること

## メモ

- 仕様書の「やや斜め」の範囲は 04 で数値にする。
