# MGW-EP-0003 流れと HUD

* **優先順位**：3（07 の WS はこの順に行う）

## ねらい

タイトルから始まり、ミス・クリア・ゲームオーバー・一時停止・増機・永久パターン防止を含めて、1 回のゲームが最後まで流れる。

## ユーザーストーリー

| 順 | ID | タイトル |
| :--- | :--- | :--- |
| 3-1 | MGW-US-0014 | タイトル画面から始める |
| 3-2 | MGW-US-0015 | HUD でスコアと残機を見る |
| 3-3 | MGW-US-0016 | ミスのあとに再登場し、残機がなくなると終わる |
| 3-4 | MGW-US-0017 | 1 面をクリアする |
| 3-5 | MGW-US-0018 | 一時停止する |
| 3-6 | MGW-US-0019 | 1,000 点で発射台が増える |
| 3-7 | MGW-US-0020 | 永久パターンを防ぐ |

## 終わりの条件

上のユーザーストーリーの受け入れ条件がすべて、自動テストか手動テストで確かめられている。
