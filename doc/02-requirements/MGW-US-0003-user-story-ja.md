# MGW-US-0003 新しい版を「更新」ボタンで受け取る

* **epic**：MGW-EP-0001
* **優先順位**：1-3
* **種類**：機能

## ストーリー

* **だれが**：プレイヤー
* **したいこと**：新しい版を、自分の決めたときに受け取る
* **なぜ**：遊んでいる途中で版が変わらないようにするため

## 受け入れ条件

| No | 条件 | 確かめ方 |
| :--- | :--- | :--- |
| 1 | 新しい版が届くと、タイトル画面とランキング画面に「更新」ボタンが出る | E2E |
| 2 | 「更新」を押すと、新しい版に切り替わって再読み込みされる | E2E |
| 3 | プレイ中（#/play）は「更新」を出さず、版も切り替わらない | E2E |
