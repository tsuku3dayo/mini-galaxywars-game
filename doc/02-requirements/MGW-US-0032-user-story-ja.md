# MGW-US-0032 ランキングを全部消す

* **epic**：MGW-EP-0006
* **優先順位**：6-4
* **種類**：機能

## ストーリー

* **だれが**：プレイヤー
* **したいこと**：ランキングの記録を全部消して、最初からやり直す
* **なぜ**：練習のときの記録を消したり、ほかの人に渡す前に空にしたりするため

## 受け入れ条件

| No | 条件 | 確かめ方 |
| :--- | :--- | :--- |
| 1 | タイトル画面に「ランキング消去」のボタンがある | E2E |
| 2 | 押すと「ランキングをすべて消します。元に戻せません。よろしいですか？」と出て、「消す」で全部消え、「やめる」では何も変わらない | 単体・E2E |
| 3 | 消したあと、タイトルの HIGH は `00000` になり、ランキング画面は記録がないときの表示になる | E2E |
| 4 | 記録がないときに押すと、「記録がありません」と出る | E2E |
| 5 | 設定（表示方式・効果音）は消えない | 単体 |
