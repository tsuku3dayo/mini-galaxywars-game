# MGW-US-0004 起動に失敗しても直せる

* **epic**：MGW-EP-0001
* **優先順位**：1-4
* **種類**：機能

## ストーリー

* **だれが**：プレイヤー
* **したいこと**：起動しないときに、自分で直せる
* **なぜ**：古いキャッシュなどで起動できなくなっても、端末の設定をいじらずに済むようにするため

## 受け入れ条件

| No | 条件 | 確かめ方 |
| :--- | :--- | :--- |
| 1 | 8 秒たってもアプリが起動しないと、復旧の画面が出る | E2E |
| 2 | 復旧の画面に「再読み込み」と「キャッシュを消して再読み込み」がある | E2E |
| 3 | 「キャッシュを消して再読み込み」をしても、ランキング（`galaxy-wars-scores`）は消えない | E2E |
