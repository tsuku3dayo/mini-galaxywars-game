# MGW-US-0013 当てた部位で得点が変わる

* **epic**：MGW-EP-0002
* **優先順位**：2-9
* **種類**：機能

## ストーリー

* **だれが**：プレイヤー
* **したいこと**：UFO のどこに当てたかで得点が変わる
* **なぜ**：狙って当てる腕前が得点に表れるようにするため

## 受け入れ条件

| No | 条件 | 確かめ方 |
| :--- | :--- | :--- |
| 1 | 側面・上部は 50 点、下部中央は 100 点、下部の突起（2 か所）は 150 点 | 単体 |
| 2 | 3 機を倒したあと、4 機目の突起に当てると 600 点 | 単体 |
| 3 | 4 機目でも、突起以外に当てたときは通常の得点 | 単体 |
| 4 | 倒した UFO の位置に爆発が 0.4 秒出て、そのあと同じ位置に入った得点が、倒してから 1 秒まで出る | 単体・手動（PC） |
| 5 | クリアしたとき、時間ボーナス max(0, 180 − 経過秒（切り捨て）) × 5 が UFO の得点に足され、合計がスコアになる。ゲームオーバーでは 0 | 単体 |
| 6 | 経過時間は、ミサイルが飛んでいる間（Playing）だけ数える。発射前・待ち・出撃待ち・一時停止の間は数えない | 単体 |
| 7 | 時間ボーナスの大きさが、遊んで納得できる（早く倒すと上乗せになる） | 手動（iPhone・PC） |

## メモ

- 600 点は 150 点の代わりに入るものとする（04 で確定）。
- 部位の形と大きさは 04 で決める（MGW-PB-0001 §6 No6）。
