# MGW-US-0019 3,000 点で発射台が増える

* **epic**：MGW-EP-0003
* **優先順位**：3-6
* **種類**：機能

## ストーリー

* **だれが**：プレイヤー
* **したいこと**：3,000 点に届くと残機が増える
* **なぜ**：得点を伸ばすごほうびのため

## 受け入れ条件

| No | 条件 | 確かめ方 |
| :--- | :--- | :--- |
| 1 | スコアが 3,000 点に届くと、残機が 1 基増え、HUD の発射台のアイコンが 1 つ増える | 単体・E2E |
| 2 | 増機は 1 回だけ | 単体 |
| 3 | 増えたときに増機音が鳴る（音は MGW-US-0023） | 単体 |

## 仕様書 §12 の受け入れ基準との対応

- 3,000点到達時に増機音が鳴り、発射台アイコンが増加すること（音は MGW-US-0023）
