# MGW-US-0010 隕石が牛耕式に動く

* **epic**：MGW-EP-0002
* **優先順位**：2-6
* **種類**：機能

## ストーリー

* **だれが**：プレイヤー
* **したいこと**：動く隕石のすき間を通してミサイルを飛ばす
* **なぜ**：障害物をよける判断の面白さのため

## 受け入れ条件

| No | 条件 | 確かめ方 |
| :--- | :--- | :--- |
| 1 | 隕石は 5 個 | 単体 |
| 2 | 隕石は画面の端で向きを変えて 1 段下がり、最下段のあとは最上段から出てくる | 単体 |
| 3 | 右へは 45 px/秒、左へは 30 px/秒で動く | 単体 |
| 4 | 隕石は 11 段で、最下段（y = 536）は発射前のミサイルの先端（y = 584）より上を通る（発射前のミサイルには当たらない） | 単体 |
| 5 | 隕石には、進む向きの後ろに尾が付き、向きが分かる | 単体・手動（PC） |

## メモ

- 初めの並び方・段の間隔・1 段下がる量・隕石の大きさは 04 で決める（MGW-PB-0001 §6 No6・No7）。
