# MGW-US-0027 ランキングを書き出す・読み込む

* **epic**：MGW-EP-0006
* **優先順位**：6-3
* **種類**：機能

## ストーリー

* **だれが**：プレイヤー
* **したいこと**：ランキングをファイルに残し、別の端末やあとで戻す
* **なぜ**：端末を替えたり、データを消したりしても記録を失わないため

## 受け入れ条件

| No | 条件 | 確かめ方 |
| :--- | :--- | :--- |
| 1 | 「書き出し」で、ランキングを JSON のファイルとして保存できる | E2E |
| 2 | 「読み込み」で、書き出した JSON からランキングを戻せる | E2E |
| 3 | 形の違う JSON や、ほかのアプリの JSON（`app` が `mini-galaxywars` でない）は読み込まず、今の記録を変えない | 単体・E2E |

## メモ

- JSON の形（版の番号を含む）は 04 で決める。
