## W（わかったこと）

- うまくいった：iPhone の実機の確認が 1 回で OK だった。入力欄を画面の上半分に置くこと、入力のあとにスクロールを戻すことを、設計（MGW-GUI-0004・MGW-TD-0004 §3）で先に決めていた。
- つまずいた：ゲームのキー操作（Space・A・D・P）を、ページ全体の keydown で受けて既定の動きを止めていたので、名前の入力欄で打った文字が入らなかった。E2E で 1 文字ずつ打つテストを書いて気づいた。設計では、文字の入力欄とゲームのキーがぶつかることを考えていなかった。
- つまずいた：ランキング画面が iPhone SE の高さに収まることを、手元では確かめたが、CI（Linux）ではフォントで行が少し高くなり、1 px はみ出して落ちた。文字の幅だけでなく、行の高さもフォントで変わる。
- つまずいた：E2E で、クリアのときに足される点数を 100 点と決め打ちにしていて、実際は 150 点で落ちた。テスト用の入口で作った場面の結果は、決め打ちせずに状態から読む方がよかった。
- 気づいた：E2E は `dist` を動かすので、`npx playwright test` をじかに動かすときは先に build が要る。忘れて、古い版で 18 件落ちた。`npm run verify`（build を含む）のあとなら起きない。
