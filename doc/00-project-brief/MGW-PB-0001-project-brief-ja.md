# ギャラクシーウォーズミニ プロジェクト概要

## 1. 目的

1979 年のアーケードゲーム『ギャラクシーウォーズ』を、iPhone の縦画面と PC のブラウザで遊べる Web アプリ（PWA）として作り直す。
自機から弾を撃つのではなく、「誘導ミサイル（自機）そのものを操って UFO に体当たりする」操作感と緊張感を再現することを、いちばんの目的にする（仕様書 §1）。
遊べるのは 1 面だけで、1 面をクリアするとゲームが終わる（仕様書 v1.1 §1）。

## 2. 範囲

### 2.1 作るもの（仕様書 §1.1 製品範囲）

| 項目 | 仕様書 |
| :--- | :--- |
| ゲームの物理と判定（ミサイル・UFO・光線・隕石、光線弾き、永久パターン防止） | §3、§5 |
| 操作（タッチ・マウス・キーボード）。タッチはプレイ空間の下の操作空間でも、プレイ空間でも操作できる | §2、§4、§20 |
| スコア（1 面の部位別の得点、600 点ボーナス、エクステンド） | §6 |
| 状態遷移と 1 面クリアの表示（クリアでゲーム終了、ランキング登録へ） | §7、§8 |
| タイトー版の挙動に固定（被弾フラッシュは赤） | §1.1、§19 |
| 擬似カラーの表示（セロハンの再現、被弾フラッシュ） | §19 |
| Web Audio での効果音の合成 | §22 |
| PWA とオフライン動作、起動に失敗したときの復旧 | §23 |
| 端末内のハイスコアランキング（上位 10 件。スコア・名前・日時。JSON の書き出し・読み込み） | §9、§21 |

選べるもの（仕様書 §1.1）：グラフィックの表示方式（ピクセルパーフェクト描画／擬似カラーセロハン）。

### 2.2 作らないもの

仕様書に書いてある除外は次のとおり。これ以外は除外しない。

- サーバーとの通信（オンラインランキング・アカウントなど）。ハイスコアと設定は端末内（localStorage）だけに保存する（§1.2、§9）。
- 乱数を使う要素。同じ入力からは必ず同じ展開とスコアになる（§1.2、§10）。
- 2 面以降。面が進むことによる難しさの変化、面ごとの得点表、面ごとのクリアメッセージ（3 面 `GOOD!!`〜33 面 `GIVE UP!!`）（§1.1、§8.1）。
- ユニバーサル版の挙動と、基板の版の切り替え（§1.1、§19）。

## 4. 成功の基準

- 仕様書 §12 の受け入れ基準をすべて満たす。それぞれに確認 ID と結果がある。
- 仕様書 §25 の再現の確認基準を満たす（外部ネットワークなしで動く、1/120 秒の物理が iPhone の実機で整合する）。
- iPhone と PC で 60 fps を保つ（§10）。

## 5. 進め方

doc/workflow.txt のとおりに進める。00〜03 は工程ごとに承認を受ける。04〜06 は承認なしで、着手前に確認を取る。07 は WS ごとに実装し、WS の終わりに手動テストを行う。
仕様を途中で変えるときは、doc/requests/ に依頼を書き、影響の一覧を承認してから仕様書の版を上げる。
